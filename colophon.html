How this website was made

I built four local HTML files styled with two external CSS files and one page-specific internal stylesheet. Each file includes an HTML5 doctype, language, character encoding, viewport, description and author information. Repeated navigation makes every page predictable. The home page introduces the store, the product page compares materials, and the order page collects a request.

Markup decisions

I used semantic elements where their meaning matched the content. For example, <article> holds advice that can stand alone, while <aside> holds supporting customer information. The price grid is a real data table, not a group of generic boxes. One <div> groups the form buttons because that pair has no more specific semantic meaning. 

<main>
  <h1>Page topic</h1>
  <section>Related content</section>
</main>

To open the project, press Ctrl + O in a browser and choose index.html. A validator should return a result such as Document checking completed. No errors or warnings to show.
