# Kamzina 199 Building Materials Store

Assignment 2 website for a real building materials store at 199 Kamzina Street, Pavlodar. The site applies CSS styling to the four semantic HTML pages built in Assignment 1.

## Open the site

Open `index.html` directly in a browser. Use the navigation menu to move between all four pages.

## Repository contents

- `index.html` - home and visit information
- `products.html` - product catalogue, prices, table and lists
- `order.html` - order and delivery form
- `colophon.html` - explanation of how the site was made
- `css/base.css` - shared stylesheet (palette, selectors, flexbox, grid, positioning, form)
- `css/damir.css` - personal stylesheet (overrides, specificity experiment)
- `images/` - real shop photographs taken by the student and retrieved from the business's 2GIS gallery
- `sketches/` - design sketches made before writing CSS
- `screenshots/` - before-styling screenshots and evidence used in the report
- `report/assignment-1-report.pdf` - Task A and Task B report
- `tag-checklist.md` - HTML tag evidence (Assignment 1)
- `css-checklist.md` - CSS technique evidence with file and line references (Assignment 2)
- `ai-log.md` - questions asked to AI during development
